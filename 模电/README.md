# 模电  

***模电是一门挺重要的课程，建议好好学***  
***不要觉得自己平时学的好就不花时间去复习QwQ***

## 资料介绍
这里有两套试卷，分别是15年的和16-17年的试卷  
然后有些老师会搞小测，将小测作为平时分的重要依据，如果恰好题一样......你也可以成为小测大神(

## 25-26秋季试题知识点/分值分布:
(顺带一提：A卷和B卷的题差不多的，A卷没考的东西B卷也不考)

#### 题型:（共100分）
##### 选择题十道题，每道题2分共20分（学了的每章都有）

##### 没有填空题

##### 简答题两道，每道题5分共10分
第一题考MOS管那块的内容，让画符号和特性曲线(有V和I的)  
第二题考功放那块的内容（A卷不记得具体靠什么了，B卷考的是甲类乙类甲乙类的θ角是多大以及哪个的效果最好）

##### 大题：
1道20分的题，5道10分的题
除了上面简答题考的两章，其他章节每章出一道题（除了第一章）

第一道10分 考的是二极管的导通，还要画个Vo的图

第二题10分 忘了

第三题20分 是三极管那章，考静态工作点，小信号模型等等

第四题10分 考差分放大电路，能求的都求了（差模共模增益还有抑制比）

第五题10分 考的是最后一章的稳压管，主要考察的应该是对电路的分析

第六题10分 考反馈电路，我不会，所以没印象了。
