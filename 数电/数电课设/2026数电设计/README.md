## 经验分享~  
#### FreedomFu27(选了交通灯):   
逻辑实现不难，但是构思方案的时候要考虑实际实现的时候可能存在的驱动不够或者其他的问题，
我们的那个项目状态机不能正常转就是因为7408的驱动不够，不是电路的问题，是芯片的问题;  
数字钟感觉芯片很多，然后手工焊接的话难度不小;  
那个测速系统太难做了。
