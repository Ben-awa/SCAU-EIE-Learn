# SCAU-EIE-LEARN

## 前言

进入大学以来，在每次考试前我都希望能收集到更多的往年试题资料，以此来提高成绩。

开始时我仅仅通过老师发的往年试题来复习，由于课程难度不大，都能轻松通过。

直到后来，我加入了学长学姐们建的QQ群，在群文件中找到了一些往年的试题，得以更充分地复习。

但是不知为何，总有些课程的试题几乎找不到，就算有也是快20年前的老古董......

然而，不同于其他学校在Github或者论坛上有着丰富的实体资源，我校的资源（至少我院）实在少得可怜。

因此，我决定建立这个项目。

在此，我也引用[浙江大学课程攻略共享计划](https://github.com/QSCTech/zju-icicles)的一段话:

*我希望只要是前人走过的弯路，后人就不必再走。这是我的信念，也是我建立这个项目的原因。*

## 特性
本项目目前收录了以下内容：

* 电子版教材  
* 平时作业&小测答案  
* 往年期末试题  
* 课程学习建议  

等等。

## 平台
Q:为什么选择Github?  
A:  
* Github有足够的知名度，容易被想要搜索资源的同学发现；  
* Github是一个开放的平台，任何人看到都可以发起提交，共同完善项目，这是把资源放在网盘所做不到的；  
* QQ 群大多为年级和专业所分隔，无法长期共同地保有。
